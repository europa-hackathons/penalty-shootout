Build images into the game

Packs your pictures into the game file, so the game works on a phone and on a shared link without an assets folder. Everything runs in this page. Nothing is uploaded. Use Chrome or Edge.

2. Choose the pictures

Open your assets folder, select all the pictures you want built in (Ctrl+A, or Cmd+A on a Mac) and choose them here. Pictures already in the game stay unless you pick a new one with the same name.
